This repository contains the latex source for the "Persistence Mechanics of the Quantum Vacuum I: The E8 Substrate and the Fine-Structure Constant"

The paper applies Persistence Mechancis to the Quantum Vacuum, deriving the fine-structure constant from first principles and presenting the theoretical foundation for the E8-Persistence Theory.

The rendered version can be viewed here: [https://meta-r0ze.github.io/PM_Quantum_Vacuum_I/Persistence_Mechanics_of_the_Quantum_Vacuum_I.pdf](https://meta-r0ze.github.io/PM_Quantum_Vacuum_I/Persistence_Mechanics_of_the_Quantum_Vacuum_I.pdf)
